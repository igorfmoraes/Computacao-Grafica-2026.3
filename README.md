# Conmputacao Grafica 2026.3
 Repositório com projetos e exercícios referentes à matéria de Computação Gráfica (MCCC007-23) ministrada pelo Prof. João Paulo Gois no 3° quadrimestre de 2026 na UFABC.
 
 ## Instalaçao e Ambiente
O `venv` é instalado junto com o próprio Python por padrão, e é o suficiente já que todos os pacotes usados são do pip. Se preferir, pode usar o Conda, mas acho exagero.
```
python -m venv .env
source .env/bin/activate
pip install -r requirements.txt
```

Instala 4 pacotes
- glfw==2.10.2
- moderngl==5.13.0
- numpy==2.5.3
- pathlib==1.0.1
